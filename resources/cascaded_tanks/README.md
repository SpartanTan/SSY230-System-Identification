## 已核对的数据字典

|变量|形状|含义|
|---|---|---|
|uEst|1024×1|估计记录：泵输入电压|
|yEst|1024×1|估计记录：下水箱传感器电压|
|uVal|1024×1|独立记录的输入；本计划保留为最终测试|
|yVal|1024×1|独立记录的输出；本计划保留为最终测试|
|Ts|1×1，值 4|采样周期 4 秒|

所有数组均为有限数值。输入为零阶保持的多正弦，主要激励范围 0–0.0144 Hz（见基准说明）。输出没有换算为米，不可直接标成水位高度。

基准说明指出：两次记录起始状态相同但未知，不处于稳态。模型可能包含平方根流量、溢出及输入相关扰动；只用简单平滑双水箱方程未必能描述全部记录。

## 本计划评价协议

1. 仅从 estimation 记录建立训练前 700 点、验证后 324 点的开发划分。
2. 在开发阶段确定结构、阶次、预处理、初态处理及调参预算。验证自由仿真可使用前缀输入推进模型，不能使用验证段真实输出反复校正。
3. 选择冻结后，可用完整 estimation 记录重估参数及共同初态。此步骤需预先声明。
4. 最后使用 uVal/yVal 一次性报告测试自由仿真。初态由训练决定；不得使用测试输出另拟合初态后仍称为同一基准协议。
5. 预测指标可另报，但要注明使用了哪些测试历史输出，以及是否属于条件预测。自由仿真与一步预测分栏显示。

不要随机打乱时序，也不要反复在 yVal 上挑模型。模型表现不好仍是有效学习结果：解释溢出、输入带宽、初态、模型阶次和噪声结构比追逐排行榜数字更重要。
